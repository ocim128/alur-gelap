## Studio v3 · Execution Steps & Output Artifacts

1. **Generate in-world character voice notes (2–6 s each):**
   - Synthesize each scripted voice note from `chat-script.json` as an individual clip using the character's assigned TTS voice (with the masculine Indonesian voice assigned to one male character).
   - Keep raw masters and ShortZ `-report.json` / `-timestamps.json` sidecars in `episodes/<slug>/sources/` (or the episode folder), and place phone-mic / voice-note derivatives (optional subtle voice-note bandpass/compression via FFmpeg so it sounds recorded on a phone) under `public/assets/<episode>/`.
   - Measure each clip's actual PCM duration via `ffprobe` and hand back exact durations so Agent 04 / `chat-script.json` aligns waveform playback and bubble holds cleanly.
   - Run an ASR spot-check where available and classify formatting diffs honestly. Record **`listening review: none`** unless a human actually listened.
2. **Prepare diegetic sound design, tension layer & UI SFX (no melodic music):**
   - Build a **location ambience bed clearly audible on phone speakers** (for example, ronda: crickets, night wind, distant dog bark, far kentongan, far motorbike) targeting **`-16` to `-15 LUFS`** integrated delivery, **`<= -2.0 dBTP`** recommended headroom (**`<= -1.5 dBTP`** hard ceiling), and **`>= -50.0 dBFS`** on every active non-overlapping 100 ms stereo RMS window (excluding `50 ms` transition edges around listed `audio.silenceDrops`; verified via `python scripts/verify-v3-export.py <delivery.mp4> <chat-script.json>`). Every listed `silenceDrop` interior (`[start + 50 ms, end - 50 ms]`) must drop **`< -50.0 dBFS`**. Exact zero-sample count is defined as individual decoded 48 kHz 2-channel float32 stereo PCM samples equal to `0.0` (L and R counted separately).
   - Layer in-world environment cues into voice notes (wind, footsteps, breath, room tone, and any scripted background audio clue such as a faint laugh audible on phone speakers).
   - Provide a **low non-melodic tension layer** (sub rumble/drone) that rises gradually from the odd detail through escalation and drops hard to near-silence at the scripted reveal silence beat.
   - Provide clean, original UI sounds (normal message pop/ping for regular characters, subtle typing taps, incoming call ringtone/vibrate if used).
   - Reserve the shared in-repo synthesized **Tanpa Nama signature notification sound** (`public/sfx/shared/tanpa-nama-ping.wav`, generated by `scripts/generate-tanpa-nama-sfx.mjs`) strictly for **Tanpa Nama** events — never play it on other characters' messages.
   - All sounds must be synthesized in-repo or properly licensed with records in `public/sfx/LICENSES.md` and `episodes/<slug>/assets.md`. Never supply melodic music. Preserve scripted silent beats.
3. **Update `assets.md` and `pipeline-state.json`:**
   - Record every clip's path, duration, voice preset/tool, synthesis/sourcing date, license/provenance, and `listening review: none` (until reviewed by ear). Set `audio` to `pass` (technical delivery complete, listening unverified) or `ready`/`fail` with explicit notes.
